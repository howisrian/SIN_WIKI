Tabelas por rotina

Rotina Tabelas Observação
conf0001 usrsys (leitura/escrita); leitura de usr_user_groups via relacionamento Senha armazenada como hash (get_password_hash).
conf0002 usr_groups, usr_group_permissions, usr_user_groups, usrsys Endpoints de grupo exigem permissões groups ou users conforme rota.

usrsys (User)

Usuário do sistema. Inclui SysIdMixin: coluna sys_id (UUID) para uso interno; não expor em API pública.

Coluna Tipo (lógico) Nulo Função Conteúdo / valores
sys_id UUID Não Identificador interno estável. Gerado pela aplicação.
usr_id inteiro Não Chave primária. —
usr_user string(50) Não Login único. Texto; único no banco.
usr_pass string(255) Não Hash da senha. Nunca armazenar senha em claro; escrita via serviço de criação/atualização.
usr_level inteiro Não Nível hierárquico numérico (legado). Default 1; semântica definida pelo produto.
usr_active boolean Não Usuário ativo. true / false.
usr_name string(100) Sim Nome exibição. —
usr_email string(100) Sim E-mail. —
usr_phone string(20) Sim Telefone. —
usr_dtcreated string(50) Sim Data criação (texto). Preenchido pelo serviço como string; formato livre acordado pelo app.
usr_dtupdated string(50) Sim Última atualização. Atualizado em update_user.
usr_lastlogin string(50) Sim Último login (texto). —
usr_idle_timeout inteiro Não Timeout de ociosidade (minutos, uso depende do front/auth). Default 15.

usr_groups (UserGroup)

Grupo de usuários para agrupar permissões. SysIdMixin inclui sys_id.

Coluna Tipo (lógico) Nulo Função Conteúdo / valores
sys_id UUID Não ID interno. —
grp_id inteiro Não PK. —
grp_name string(80) Não Nome do grupo. Único.
grp_desc string(200) Sim Descrição. —
grp_active boolean Não Grupo ativo. Grupos inativos não entram na fusão de permissões do usuário.

usr_group_permissions (GroupPermission)

Uma linha por par (grupo, module_key). Restrição única (grp_id, module_key).

Coluna Tipo (lógico) Nulo Função Conteúdo / valores
id inteiro Não PK surrogate. —
grp_id FK → usr_groups Não Grupo dono da permissão. —
module_key string(60) Não Chave do módulo/tela no front. Ex.: users, groups, pdv0001. Deve bater com require_permission(module_key, …) e com as chaves do menu.
can_view boolean Não Permite visualizar. Default false.
can_create boolean Não Permite criar. —
can_update boolean Não Permite alterar. —
can_delete boolean Não Permite excluir. —

usr_user_groups (UserGroupLink)

Associação N:N usuário ↔ grupo. Unicidade (usr_id, grp_id).

Coluna Tipo (lógico) Nulo Função Conteúdo / valores
id inteiro Não PK. —
usr_id FK → usrsys Não Usuário. —
grp_id FK → usr_groups Não Grupo. —

Permissões em runtime

API/app/core/permissions.py — get_user_permissions percorre grupos ativos do usuário e agrega flags com OR. require_permission("groups", "can_view") exige que exista entrada com module_key == "groups" e flag correspondente true.
