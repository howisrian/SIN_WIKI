conf0001 Usuários

CRUD essencial de usuários da tabela usrsys: criar com senha hash, listar com grupos carregados, atualizar campos e senha.

Prefixo API: /conf/users · Código: API/app/modules/conf/routines/conf0001/ · App: chave de página users

Frontend

Página mapeada em app/src/App.jsx como users: UsersPage.

  • Arquivos esperados: app/src/pages/conf/conf0001/UsersPage.jsx e componentes auxiliares (ex. UserFormPanel.jsx).
  • Observação: em alguns clones do repositório os arquivos podem existir sob APP/src/pages/conf/conf0001/; mantenha um único caminho canônico alinhado ao import do App.jsx.
  • Listagem e edição consomem GET /conf/users/list e PUT /conf/users/{usr_id}; criação usa POST /conf/users/create.

API (FastAPI)

Todas as rotas abaixo exigem token válido (dependência global do roteador /conf em API/app/main.py). Não há require_permission nesta rotina: qualquer usuário autenticado pode chamar estes endpoints (avalie endurecer com permissão users se necessário).

Método Endpoint Descrição
POST /conf/users/create Body: UserCreate — usr_user, usr_pass (plain → hash), usr_level, usr_active, opcionais nome/e-mail/telefone/datas. Erro 400 se login duplicado.
GET /conf/users/list Lista usuários com relacionamento groups (pares usuário–grupo).
PUT /conf/users/{usr_id} Body: UserUpdate — campos opcionais; se usr_pass vier preenchido, substitui por hash.

Arquivos: routes.py, services.py, schemas.py.

Tabelas

Principal: usrsys (User). Vínculo com grupos: usr_user_groups. Detalhes em conf-dados.html.
