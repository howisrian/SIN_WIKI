conf0002 Grupos e permissões

Cadastro de grupos com permissões por module_key (ver, criar, alterar, excluir), atribuição de grupos a usuários e leitura das permissões efetivas do usuário logado.

Prefixo API: /conf/groups · Permissões: API/app/core/permissions.py · Front: app/src/pages/conf/conf0002/GroupsPage.jsx

Frontend

app/src/pages/conf/conf0002/GroupsPage.jsx · GroupFormPanel.jsx · conf0002.css

  • Lista de módulos disponíveis para a matriz de permissões está em AVAILABLE_MODULES (chave key = valor gravado em module_key).
  • Ao salvar grupo, envia lista de permissões com can_view, can_create, can_update, can_delete por módulo.
  • Vínculo de grupos a usuários usa PUT /conf/groups/users/{usr_id}/assign com corpo { "grp_ids": [...] }.

API (FastAPI)

Rotas protegidas por require_permission(module_key, ação), exceto GET /conf/groups/me/permissions, que usa apenas o usuário atual.

Método Endpoint Permissão Descrição
POST /conf/groups/create groups · can_create Body GroupCreate: nome, descrição, ativo, lista de permissions. Não permite module_key duplicado no mesmo grupo.
GET /conf/groups/list groups · can_view Grupos com permissões e usuários vinculados.
PUT /conf/groups/{grp_id} groups · can_update Body GroupUpdate. Se permissions for enviado, substitui todas as linhas do grupo em usr_group_permissions.
PUT /conf/groups/users/{usr_id}/assign users · can_update Body UserGroupAssignIn (grp_ids). Remove vínculos anteriores e recria.
GET /conf/groups/me/permissions — Permissões agregadas do usuário autenticado (união OR entre grupos ativos).

Arquivos: routes.py, services.py, schemas.py.

Chaves de módulo (module_key)

Devem coincidir com as chaves de menu/página usadas no React (ex.: users, groups, dashboard, pdv0001). O backend compara literalmente na checagem require_permission("groups", "can_view"), etc.

Fusão de permissões: se um usuário pertence a vários grupos ativos, get_user_permissions faz OR por module_key em cada flag (can_view, …).

Tabelas

usr_groups, usr_group_permissions, usr_user_groups; usuários em usrsys. Ver conf-dados.html.
