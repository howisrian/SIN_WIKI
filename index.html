Início

Esta versão da wiki foi montada com base no repositório real que você anexou. A ideia aqui não é ser bonita, e sim ser fácil de usar e crescer junto com o projeto.

Ordem recomendada para um programador novo: Como usar a wiki → Fluxo real do projeto → Estrutura do repositório → Backend real → Frontend real → Módulos existentes → Tabelas principais.

Backend

FastAPI com módulos separados por assunto e rotinas.

Frontend

React + Vite com páginas por módulo.

Banco

Models por módulo e migrations com Alembic.

Padrão

Módulo → rotina → rotas → service → telas.
